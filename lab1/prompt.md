# Рабочий промпт лабораторной 1

Задача сформулирована в текущей сессии разработки на основе задания курса.
Ниже зафиксировано техническое задание для LLM, а не дословная стенограмма чата.

Создай Telegram-бота «ДелоБот» на Python с python-telegram-bot для личных рабочих
задач участников небольшой команды. Команды /start, /help, /add high|normal|low текст,
/tasks, /search текст, /done номер, /remind номер минуты. Обычный текст добавляет задачу.
Храни задачи в SQLite, изолируй пользователей по Telegram ID. Напоминания должны
сохраняться после перезапуска. Работай в личных чатах, отвечай по-русски, добавь
кнопки списка задач и помощи. Проверяй ввод, обрабатывай ошибки. Секреты бери из .env.
Создай bot.py, storage.py, requirements.txt, README.md, .env.example и .gitignore.

## Уточнения и итоговое ТЗ

Добавить разумные пределы длины, проверку владельца при завершении и напоминании,
разбиение длинных ответов, отсутствие токенов и пользовательского текста в логах.
Проверить обработчики команды и кнопки автоматическими тестами с подменой Telegram API.
Текущая реализация соответствует этому итоговому ТЗ; живое Telegram-демо ещё требуется.
