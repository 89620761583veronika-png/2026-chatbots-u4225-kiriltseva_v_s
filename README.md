Курс ИТМО «Vibe Coding: AI-боты для бизнеса».

ДелоБот помогает сотрудникам небольшой команды вести личные рабочие задачи в Telegram:
добавлять, искать, сортировать по приоритету, завершать и получать напоминания.
Задачи сохраняются в SQLite. Для загрузки списка из рабочего файла есть импорт CSV.
Команда `/feedback` собирает оценки и предложения для проверки продукта.
Код создан с помощью LLM в Codex; рабочие промпты сохранены в папках лабораторных.
Боту не нужен платный API нейросети: LLM используется на этапе разработки.

## Быстрый запуск

[Статус подготовки окружения](docs/preparation.md).

Требуется Python **3.10+**, рекомендуется 3.12. Встроенный Python 3.9 на этом Mac не подходит.
Окружение `.venv` в текущей рабочей папке уже подготовлено.

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, название «ДелоБот» и username `itmoftmi_kvs_bot`.
   Если занят, попробуйте `itmoftmi_kvs2026_bot`.
3. Скопируйте токен в локальный `.env`: `BOT_TOKEN=полученный_токен`.
   `.env` исключён из Git. Не включайте токен в скриншоты и отчёты.
4. Выполните в папке проекта:

```bash
.venv/bin/python bot.py
```

Для чистого клона на другом компьютере:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN в .env, затем:
.venv/bin/python bot.py
```

Чтобы увидеть статистику, отправьте боту `/myid`, добавьте полученное число в
`ADMIN_USER_ID` в `.env` и перезапустите процесс. По умолчанию административные
команды закрыты для всех.

## Команды

| Команда | Пример и результат |
| --- | --- |
| `/start`, `/help` | Справка и кнопки быстрого доступа |
| `/add` | `/add high Подготовить встречу` — новая задача |
| Обычный текст | Создаёт задачу с приоритетом `normal` |
| `/tasks` | Открытые задачи: сначала `high`, затем `normal`, затем `low` |
| `/search` | `/search встречу` — поиск без учёта регистра |
| `/done` | `/done 1` — завершить собственную задачу №1 |
| `/remind` | `/remind 1 30` — напомнить через 30 минут |
| `/sample` | Скачать пример CSV; отправить файл для импорта |
| `/feedback` | `/feedback 5 Удобно, хотелось бы сроки` |
| `/myid` | Узнать свой Telegram ID |
| `/stats`, `/reviews` | Сводка и экспорт отзывов для владельца |

Работа только в личных чатах. Каждый участник ведёт собственный список; общего
распределения задач между участниками в этой версии нет. CSV содержит строго
`title,priority`, до 100 строк и до 100 КБ, кодировка UTF-8. Повторный импорт
создаёт новые задачи. Напоминания проверяются каждые 30 секунд; после простоя
просроченные напоминания отправляются при запуске. При сетевой ошибке возможна
повторная доставка; бот не обещает доставку строго один раз.

Отзывы сохраняют Telegram ID, оценку, комментарий и дату. Владелец видит их через
`/reviews`; это не анонимный опрос. Данные пользователей и реальные отзывы
не публикуются в репозитории. SQLite и напоминания переживают перезапуск.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
```

Проверяются изоляция пользователей, сохранение данных, CSV и его ошибки,
приоритеты, поиск, восстановление напоминаний, статистика, доступ администратора,
обработка команд и кнопок. Telegram API в тестах заменён тестовыми объектами.
Результат записан в [docs/verification.md](docs/verification.md).

## Деплой

Выбран **Docker + VPS** с постоянным томом SQLite:

```bash
docker compose up -d --build
docker compose logs --tail=50 bot
docker compose ps
```

Подробности: [docs/deployment.md](docs/deployment.md).
Бот использует long polling, поэтому webhook, публичный HTTP URL и ngrok не нужны.
Одновременно должен работать один экземпляр бота с этим токеном.
