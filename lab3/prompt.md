# Рабочий промпт лабораторной 3

Техническое задание для LLM в текущей сессии; не дословная стенограмма.

Подготовь ДелоБота к Docker + VPS. Создай Dockerfile, compose.yaml с перезапуском и
постоянным томом SQLite, .dockerignore и GitHub Actions для тестов.
Используй long polling, один экземпляр, без webhook. Добавь /feedback оценка комментарий,
сохранение отзывов, /stats и /reviews только для ADMIN_USER_ID из переменных окружения.
Считай отдельно число отзывов и уникальных авторов, не записывай вымышленные отзывы.
Подготовь инструкцию деплоя, план пилота на 3–5 человек, сценарий демо и отчёт со статусами.

## Итоговые уточнения

Запускай контейнер от непривилегированного пользователя. Добавь защиту CSV-экспорта
от формул Excel, инструкцию резервного копирования и объяснение хранения Telegram ID.
Не заявляй успешный деплой, стабильность и улучшения по фидбеку до реального пилота.
